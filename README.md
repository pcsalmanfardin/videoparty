# VideoParty 🎬

একসাথে ভিডিও দেখার জন্য ২-জনের একটা ওয়েব অ্যাপ — ভিডিও ফাইল আপলোড করুন বা YouTube লিংক পেস্ট করুন, দুইজনের প্লেয়ার সবসময় সিঙ্কে থাকবে, আর সাথে লাইভ ভয়েস, টেক্সট চ্যাট ও ইমোজি রিয়্যাকশন।

## যা যা আছে

- **ভিডিও সিঙ্ক** — play/pause/seek একজন করলে অন্যজনের প্লেয়ারেও সাথে সাথে হয়ে যায়
- **ভিডিও উৎস** — নিজের ডিভাইস থেকে ফাইল আপলোড, অথবা YouTube লিংক
- **ভয়েস চ্যাট** — WebRTC দিয়ে সরাসরি পিয়ার-টু-পিয়ার (সার্ভারে ভয়েস রেকর্ড/স্টোর হয় না)
- **টেক্সট চ্যাট ও ইমোজি রিয়্যাকশন**
- **রুম সিস্টেম** — একটা রুম কোড শেয়ার করে বন্ধুকে যোগ করান (রুমপ্রতি সর্বোচ্চ ২ জন)

## লোকালি চালানো

```bash
npm install
npm start
```

তারপর ব্রাউজারে `http://localhost:3000` খুলুন। দ্বিতীয় ট্যাব/ডিভাইসে একই লিংক খুলে একই রুম কোড দিয়ে যোগ দিন।

## ইন্টারনেটে ডিপ্লয় করা (বন্ধুর সাথে ব্যবহারের জন্য)

লোকাল লিংক শুধু আপনার নিজের কম্পিউটারে কাজ করবে। বন্ধু যাতে যোগ দিতে পারে, সেজন্য এটা কোনো হোস্টিং সার্ভিসে ডিপ্লয় করতে হবে। সহজ অপশনগুলো:

- **[Render.com](https://render.com)** — ফ্রি টিয়ারে Node.js ওয়েব সার্ভিস চালানো যায়। GitHub রিপোতে কোড পুশ করে Render-এ কানেক্ট করুন, Build command: `npm install`, Start command: `npm start`।
- **[Railway.app](https://railway.app)** — একইভাবে GitHub রিপো কানেক্ট করে ডিপ্লয় করা যায়।
- **নিজের VPS** — Node.js ইনস্টল করা যেকোনো সার্ভারে `npm install && npm start` চালিয়ে একটা রিভার্স প্রক্সি (nginx) দিয়ে HTTPS সেট করুন।

⚠️ **HTTPS জরুরি**: ভয়েস চ্যাটের জন্য ব্রাউজার `getUserMedia` (মাইক্রোফোন অ্যাক্সেস) শুধু HTTPS বা `localhost`-এ কাজ করে। তাই লাইভ ডিপ্লয়মেন্টে HTTPS থাকতেই হবে — উপরের হোস্টিং সার্ভিসগুলো এটা ডিফল্টভাবেই দেয়।

## স্থায়ী ভিডিও স্টোরেজ (Cloudflare R2) — সেট করা জোরালোভাবে সুপারিশ করা হচ্ছে

ফ্রি হোস্টিং প্ল্যানের ডিস্ক সাধারণত সাময়িক (ephemeral) — সার্ভার ঘুম থেকে জাগলে বা রিডিপ্লয় হলে `uploads/` ফোল্ডারের ফাইল হারিয়ে যেতে পারে, তখন ভিডিও আবার আপলোড করতে হয়। এটা এড়াতে এই অ্যাপ **Cloudflare R2**-এ (ফ্রি, স্থায়ী অবজেক্ট স্টোরেজ, ১০GB পর্যন্ত ফ্রি, কোনো এক্সপায়ারি নেই) আপলোড করার সাপোর্ট রাখে। R2 কনফিগার করা থাকলে:
- ভিডিও ফাইল স্থায়ীভাবে থাকবে, সার্ভার যতবার রিস্টার্ট হোক না কেন
- রুমে "কোন ভিডিও চলছে" তথ্যও R2-তে সেভ থাকে, তাই রিস্টার্টের পরও রুমে ফিরলে ভিডিও আবার সিলেক্ট করার দরকার হবে না

**R2 কনফিগার না করলে** অ্যাপ আগের মতোই লোকাল ডিস্কে সেভ করবে (টেস্টিং-এর জন্য ঠিক আছে, কিন্তু ফ্রি হোস্টিং-এ স্থায়ী না)।

### R2 বাকেট বানানো (একবারই করতে হবে)

1. [dash.cloudflare.com](https://dash.cloudflare.com) এ ফ্রি একাউন্ট খুলুন
2. বামের মেনু থেকে **R2 Object Storage** এ যান, **Create bucket** ক্লিক করে একটা নাম দিন (যেমন `videoparty`)
3. বাকেট তৈরির পর **Settings** ট্যাবে গিয়ে **Public Access** চালু করুন — এখানে একটা পাবলিক `r2.dev` URL পাবেন (যেমন `https://pub-xxxxxxxx.r2.dev`), এটাই `R2_PUBLIC_URL`
4. R2 ড্যাশবোর্ডের **Manage R2 API Tokens** থেকে একটা নতুন API token বানান (Read & Write পারমিশন সহ) — এখান থেকে পাবেন `Access Key ID`, `Secret Access Key`, আর `Account ID`
5. Render ড্যাশবোর্ডে আপনার সার্ভিসে গিয়ে **Environment** ট্যাবে নিচের ৫টা ভ্যারিয়েবল যোগ করুন (মান বসিয়ে):

   ```
   R2_ACCOUNT_ID=...
   R2_ACCESS_KEY_ID=...
   R2_SECRET_ACCESS_KEY=...
   R2_BUCKET_NAME=videoparty
   R2_PUBLIC_URL=https://pub-xxxxxxxx.r2.dev
   ```

6. Save করলে Render নিজে থেকেই সার্ভিস রিডিপ্লয় করবে। ডিপ্লয় লগে `R2 storage: ENABLED` দেখলে বুঝবেন ঠিকমতো কনফিগার হয়েছে।

লোকালি টেস্ট করতে চাইলে `.env.example` কপি করে `.env` বানিয়ে একই মানগুলো বসান (dotenv প্যাকেজ ছাড়া চালাতে চাইলে টার্মিনালে `export` করে দিতে পারেন, অথবা `npm i dotenv` করে `server.js`-এর শুরুতে `require('dotenv').config()` যোগ করে নিন)।

## সীমাবদ্ধতা ও ভবিষ্যতে যা যোগ করা যায়

- **Google Drive-এর মতো লিংক**: এগুলোর কোনো পাবলিক sync API নেই, তাই এই অ্যাপ শুধু লিংকটা দুইজনকেই দেখায় (আলাদা ট্যাবে খুলতে হবে) — play/pause automatic sync হবে না। YouTube আর সরাসরি আপলোড করা ফাইলের জন্য পূর্ণ সিঙ্ক কাজ করে।
- **R2 ফ্রি সীমা**: মাসে ১০GB স্টোরেজ, ১০ লাখ রিড ও ১০ লাখ রাইট অপারেশন ফ্রি — ২ জনের ব্যবহারের জন্য এটা অনেক বেশি, চিন্তার কিছু নেই।
- **NAT/ফায়ারওয়াল**: ভয়েস চ্যাট Google-এর ফ্রি STUN সার্ভার ব্যবহার করে। কিছু রেস্ট্রিক্টিভ নেটওয়ার্কে (কর্পোরেট ফায়ারওয়াল ইত্যাদি) এটা কানেক্ট নাও হতে পারে — তখন একটা TURN সার্ভার (যেমন [Twilio](https://www.twilio.com/stun-turn) বা [Metered](https://www.metered.ca/tools/openrelay/)) `rtcConfig`-এ (public/client.js) যোগ করতে হবে।
- **২ জনের বেশি**: এটা ইচ্ছাকৃতভাবে ২ জনের জন্য বানানো (সিম্পল signaling)। বেশি মানুষের জন্য একটা SFU (mediasoup/LiveKit) লাগবে।
