# VideoParty 🎬

একসাথে ভিডিও দেখার জন্য ২-জনের একটা ওয়েব অ্যাপ — ভিডিও ফাইল আপলোড করুন বা YouTube লিংক পেস্ট করুন, দুইজনের প্লেয়ার সবসময় সিঙ্কে থাকবে, আর সাথে লাইভ ভয়েস, টেক্সট চ্যাট ও ইমোজি রিয়্যাকশন।

## যা যা আছে

- **ভিডিও সিঙ্ক** — play/pause/seek একজন করলে অন্যজনের প্লেয়ারেও সাথে সাথে হয়ে যায়
- **ভিডিও উৎস** — নিজের ডিভাইস থেকে ফাইল আপলোড, অথবা YouTube লিংক
- **ভয়েস চ্যাট** — WebRTC দিয়ে সরাসরি পিয়ার-টু-পিয়ার (সার্ভারে ভয়েস রেকর্ড/স্টোর হয় না)
- **টেক্সট চ্যাট ও ইমোজি রিয়্যাকশন**
- **রুম সিস্টেম** — একটা রুম কোড শেয়ার করে বন্ধুকে যোগ করান (রুমপ্রতি সর্বোচ্চ ২ জন)

## লোকালি চালানো

```bash
npm install
npm start
```

তারপর ব্রাউজারে `http://localhost:3000` খুলুন। দ্বিতীয় ট্যাব/ডিভাইসে একই লিংক খুলে একই রুম কোড দিয়ে যোগ দিন।

## ইন্টারনেটে ডিপ্লয় করা (বন্ধুর সাথে ব্যবহারের জন্য)

লোকাল লিংক শুধু আপনার নিজের কম্পিউটারে কাজ করবে। বন্ধু যাতে যোগ দিতে পারে, সেজন্য এটা কোনো হোস্টিং সার্ভিসে ডিপ্লয় করতে হবে। সহজ অপশনগুলো:

- **[Render.com](https://render.com)** — ফ্রি টিয়ারে Node.js ওয়েব সার্ভিস চালানো যায়। GitHub রিপোতে কোড পুশ করে Render-এ কানেক্ট করুন, Build command: `npm install`, Start command: `npm start`।
- **[Railway.app](https://railway.app)** — একইভাবে GitHub রিপো কানেক্ট করে ডিপ্লয় করা যায়।
- **নিজের VPS** — Node.js ইনস্টল করা যেকোনো সার্ভারে `npm install && npm start` চালিয়ে একটা রিভার্স প্রক্সি (nginx) দিয়ে HTTPS সেট করুন।

⚠️ **HTTPS জরুরি**: ভয়েস চ্যাটের জন্য ব্রাউজার `getUserMedia` (মাইক্রোফোন অ্যাক্সেস) শুধু HTTPS বা `localhost`-এ কাজ করে। তাই লাইভ ডিপ্লয়মেন্টে HTTPS থাকতেই হবে — উপরের হোস্টিং সার্ভিসগুলো এটা ডিফল্টভাবেই দেয়।

## স্থায়ী ভিডিও স্টোরেজ (Backblaze B2) — সেট করা জোরালোভাবে সুপারিশ করা হচ্ছে

ফ্রি হোস্টিং প্ল্যানের ডিস্ক সাধারণত সাময়িক (ephemeral) — সার্ভার ঘুম থেকে জাগলে বা রিডিপ্লয় হলে `uploads/` ফোল্ডারের ফাইল হারিয়ে যেতে পারে, তখন ভিডিও আবার আপলোড করতে হয়। এটা এড়াতে এই অ্যাপ **Backblaze B2**-এ (ফ্রি, স্থায়ী S3-কম্প্যাটিবল অবজেক্ট স্টোরেজ, ১০GB পর্যন্ত ফ্রি, কোনো এক্সপায়ারি নেই) আপলোড করার সাপোর্ট রাখে। B2 কনফিগার করা থাকলে:
- ভিডিও ফাইল স্থায়ীভাবে থাকবে, সার্ভার যতবার রিস্টার্ট হোক না কেন
- রুমে "কোন ভিডিও চলছে" তথ্যও B2-তে সেভ থাকে, তাই রিস্টার্টের পরও রুমে ফিরলে ভিডিও আবার সিলেক্ট করার দরকার হবে না

**B2 কনফিগার না করলে** অ্যাপ আগের মতোই লোকাল ডিস্কে সেভ করবে (টেস্টিং-এর জন্য ঠিক আছে, কিন্তু ফ্রি হোস্টিং-এ স্থায়ী না)।

⚠️ **বাকেট অবশ্যই Private রাখুন** — Backblaze-এ বাকেট Public করলে কার্ড/পেমেন্ট মেথড চায়, কিন্তু Private রাখলে চায় না। এই অ্যাপ বাকেট Private রেখেই কাজ করে: ব্রাউজার ভিডিওটা সরাসরি B2 থেকে না নিয়ে আমাদের নিজের সার্ভারের `/media/...` রুট দিয়ে নেয়, আর সার্ভার প্রতিবার একটা সাময়িক (কয়েক ঘণ্টার জন্য বৈধ) সিকিউর লিংক বানিয়ে ভিডিওটা দেখায়। তাই বাকেট পাবলিক করার দরকারই নেই।

### B2 বাকেট বানানো (একবারই করতে হবে, কার্ড লাগবে না)

1. [backblaze.com/sign-up/cloud-storage](https://www.backblaze.com/sign-up/cloud-storage) এ ফ্রি একাউন্ট খুলুন (কোনো কার্ড চাইবে না)
2. লগইন করে **B2 Cloud Storage** → **Buckets** এ যান, **Create a Bucket** ক্লিক করে নাম দিন (যেমন `videoparty`), Privacy Setting-এ **Private** সিলেক্ট করুন (এটাই ঠিক, Public না করলে কোনো কার্ড চাইবে না)
3. বাকেট তৈরি হলে বাকেটের ডিটেইলস পেজে **Endpoint** দেখতে পাবেন, যেমন `s3.us-west-004.backblazeb2.com` — এখান থেকে endpoint এবং region code (যেমন `us-west-004`) দুটোই নিন
4. বামের মেনু থেকে **Application Keys** এ যান, **Add a New Application Key** ক্লিক করুন। নাম দিন, বাকেট হিসেবে আপনার `videoparty` বাকেট সিলেক্ট করুন, Read & Write অ্যাক্সেস দিন। তৈরি হলে সাথে সাথেই **keyID** ও **applicationKey** দেখাবে — এই দুটো এখনই কপি করে রাখুন (পরে আর দেখাবে না)
5. Render ড্যাশবোর্ডে আপনার সার্ভিসে গিয়ে **Environment** ট্যাবে নিচের ৫টা ভ্যারিয়েবল যোগ করুন (মান বসিয়ে):

   ```
   B2_KEY_ID=...
   B2_APPLICATION_KEY=...
   B2_ENDPOINT=s3.us-west-004.backblazeb2.com
   B2_REGION=us-west-004
   B2_BUCKET_NAME=videoparty
   ```

6. Save করলে Render নিজে থেকেই সার্ভিস রিডিপ্লয় করবে। ডিপ্লয় লগে `B2 storage: ENABLED` দেখলে বুঝবেন ঠিকমতো কনফিগার হয়েছে।

লোকালি টেস্ট করতে চাইলে `.env.example` কপি করে `.env` বানিয়ে একই মানগুলো বসান (dotenv প্যাকেজ ছাড়া চালাতে চাইলে টার্মিনালে `export` করে দিতে পারেন, অথবা `npm i dotenv` করে `server.js`-এর শুরুতে `require('dotenv').config()` যোগ করে নিন)।

## কিল সুইচ — যখন খুশি পুরো সাইট বন্ধ/চালু করা

ডিফল্টভাবে, লিংকটা যার কাছেই থাকুক, সে রুম বানাতে/জয়েন করতে/ভিডিও আপলোড করতে পারবে। এর বদলে **শুধু আপনি** নিয়ন্ত্রণ করতে চাইলে — বন্ধুকে কোনো পাসওয়ার্ড মনে রাখতে হবে না, বরং সাইটটা এমনিতেই বন্ধ থাকবে যতক্ষণ না আপনি নিজে চালু করছেন — Render-এর **Environment** ট্যাবে একটা `ADMIN_KEY` যোগ করুন (একটা লম্বা, অনুমান করা কঠিন এমন কিছু):

```
ADMIN_KEY=এটা-শুধু-আপনার-জানা-একটা-লম্বা-গোপন-কোড
```

এটা যোগ করার পর:

- আপনার একটা গোপন **অ্যাডমিন লিংক** তৈরি হয়ে যাবে: `https://আপনার-অ্যাপ.onrender.com/admin/আপনার-ADMIN_KEY`
- এই লিংকে গিয়ে এক ক্লিকে সাইট **চালু/বন্ধ** করতে পারবেন
- সাইট "বন্ধ" থাকলে, কেউ (এমনকি সরাসরি অ্যাপের লিংক দিয়েও) রুম বানাতে, জয়েন করতে, বা ভিডিও দেখতে/আপলোড করতে পারবে না — একটা "এই মুহূর্তে বন্ধ আছে" মেসেজ দেখাবে
- বন্ধুকে শুধু সাধারণ অ্যাপের লিংকটা দিলেই হবে — কোনো পাসওয়ার্ড লাগবে না, আপনি সাইট চালু রাখলেই সে ঢুকতে পারবে
- অ্যাডমিন লিংকটা **শুধু আপনার কাছেই** থাকবে — এটা কাউকে শেয়ার করবেন না
- এই "সাইট চালু আছে কিনা" তথ্যটাও B2-তে সেভ থাকে (B2 কনফিগার করা থাকলে), তাই সার্ভার রিস্টার্ট হলেও সুইচের অবস্থান মনে থাকবে। B2 কনফিগার না থাকলে প্রতি রিস্টার্টে এটা ডিফল্ট "চালু" অবস্থায় ফিরে যাবে
- `ADMIN_KEY` না দিলে এই ফিচারটা বন্ধ থাকবে এবং সাইট সবসময় সবার জন্য খোলা থাকবে (আগের মতো)

⚠️ অ্যাডমিন লিংকটা ব্রাউজার হিস্ট্রিতে থেকে যেতে পারে, তাই শেয়ার্ড/পাবলিক কম্পিউটারে এটা খোলা থেকে সাবধান থাকুন।

## সীমাবদ্ধতা ও ভবিষ্যতে যা যোগ করা যায়

- **Google Drive-এর মতো লিংক**: এগুলোর কোনো পাবলিক sync API নেই, তাই এই অ্যাপ শুধু লিংকটা দুইজনকেই দেখায় (আলাদা ট্যাবে খুলতে হবে) — play/pause automatic sync হবে না। YouTube আর সরাসরি আপলোড করা ফাইলের জন্য পূর্ণ সিঙ্ক কাজ করে।
- **B2 ফ্রি সীমা**: মাসে ১০GB স্টোরেজ ফ্রি (স্থায়ী, এক্সপায়ার হয় না), এবং স্টোর করা ডেটার ৩ গুণ পর্যন্ত ফ্রি egress (ডাউনলোড ব্যান্ডউইথ) — ২ জনের ব্যবহারের জন্য এটা যথেষ্টের চেয়ে বেশি।
- **NAT/ফায়ারওয়াল**: ভয়েস চ্যাট Google-এর ফ্রি STUN সার্ভার ব্যবহার করে। কিছু রেস্ট্রিক্টিভ নেটওয়ার্কে (কর্পোরেট ফায়ারওয়াল ইত্যাদি) এটা কানেক্ট নাও হতে পারে — তখন একটা TURN সার্ভার (যেমন [Twilio](https://www.twilio.com/stun-turn) বা [Metered](https://www.metered.ca/tools/openrelay/)) `rtcConfig`-এ (public/client.js) যোগ করতে হবে।
- **২ জনের বেশি**: এটা ইচ্ছাকৃতভাবে ২ জনের জন্য বানানো (সিম্পল signaling)। বেশি মানুষের জন্য একটা SFU (mediasoup/LiveKit) লাগবে।
